# Diwey.dev — Portfolio

Portfolio de Loftur, développeur frontend, réalisé en formation Intégrateur Web (OpenClassrooms, 2025-2026).

## Stack

- React 18 + Vite
- Sass (CSS natif, architecture en couches : reset → tokens → base → composants)
- React Router (Accueil, Portfolio, fiches projet, Contact)

## Lancer le projet en local

Prérequis : Node.js (version LTS recommandée).

```bash
npm install
npm run dev
```

Le site s'ouvre automatiquement dans Firefox (ouvrir http://localhost:5173).

## Build de production

```bash
npm run build
```

Génère le site optimisé dans `dist/`.
